# MoodJournal Features

## 🎨 Theme System

### Available Themes
- **Light Mode**: Clean, bright interface for daytime use
- **Dark Mode**: Easy on the eyes for low-light environments  
- **System Theme**: Automatically follows your device preference

### Customization Options
- **Instant Switching**: Changes apply immediately without page reload
- **Cross-Device Sync**: Theme preferences sync across all devices
- **Accessibility**: High contrast options for better readability
- **Modern Colors**: Professional purple primary with neutral grays

### How to Change Theme
1. Go to Settings page
2. Click on "Theme" tab
3. Select your preferred option:
   - **System**: Follows device settings (recommended)
   - **Light**: Always light theme
   - **Dark**: Always dark theme

## 🌤️ Weather Integration

### Automatic Weather Data
- **Location-Based**: Weather fetched when you add location to entries
- **Historical Support**: Weather data for past 5 days available
- **Smart Caching**: Prevents duplicate API calls for same location/date
- **Nearby Sharing**: Uses cached data from locations within 5km

### Weather Information Displayed
- **Temperature**: Current temperature and "feels like"
- **Conditions**: Weather description with icons
- **Details**: Humidity, wind speed, pressure, visibility
- **Context**: Adds environmental context to your journal entries

### Setup Requirements
1. **API Key**: Free account at https://openweathermap.org/api
2. **Environment**: Add `OPENWEATHERMAP_API_KEY` to your configuration
3. **Usage**: 1,000 free API calls per day
4. **Automatic**: Works immediately once configured
